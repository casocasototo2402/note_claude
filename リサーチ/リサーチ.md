## 実行ログ（2026-09-21）

### 実施済み
- `yt-dlp` をインストール（2026.08.19）。`jq` は導入済み（jq-1.7）。
- `リサーチ/collect.sh` を作成。ネットワーク非依存のロジック（条件フィルタ・
  登録者比ランキング・同一チャンネル上限・VTT→テキスト変換・一覧表生成）は
  合成データで動作検証済み。

### ブロック要因
実行環境の egress ポリシーにより **`youtube.com` への接続が遮断**されています。

```
$ curl -sS "$HTTPS_PROXY/__agentproxy/status" | jq '.recentRelayFailures'
  "host": "www.youtube.com:443",
  "detail": "gateway answered 403 to CONNECT (policy denial or upstream failure)"
```

yt-dlp は検索・メタデータ・字幕のいずれも取得できません。

### 代替経路の調査結果
| 経路 | 到達可否 | 判定 |
|---|---|---|
| `youtube.com`（yt-dlp） | ✗ 403 CONNECT拒否 | 検索・メタデータ・字幕すべて不可 |
| `www.googleapis.com`（YouTube Data API v3） | ○ 到達可 | APIキーがあればメタデータは取得可。ただし**字幕は不可** |

YouTube Data API の `captions.download` は**チャンネル所有者のOAuth認証が必須**のため、
他人の動画の字幕は公式APIでは取得できません。字幕を含む本リサーチは
`youtube.com` への接続が前提になります。

### YouTube Data API 版の用意（2026-09-22 追加）
`リサーチ/collect_api.sh` を追加し、APIキーの置き場（`.env`）を用意しました。
**キーを入れれば即実行できる状態**です。

```bash
cp .env.example .env
# .env の YOUTUBE_API_KEY= に発行したキーを貼る
bash リサーチ/collect_api.sh
```

- `.env` は `.gitignore` 済み。キーがリポジトリに入ることはありません。
- 環境変数 `YOUTUBE_API_KEY` が設定されていればそちらが優先されます。
- 配線は検証済み（ダミーキーで Google から `API key not valid` が返るところまで確認）。

**ただし字幕は取得できません。** API版で集まるのは以下です。

| 取得できるもの | 取得できないもの |
|---|---|
| タイトル / 概要欄 / タグ | **字幕（本文）** |
| 再生数 / 高評価数 / コメント数 | |
| 登録者数（非公開チャンネルは除外） | |
| 上位コメント20件 | |

そのため第2章は「字幕の内容から」ではなく
**「タイトル・概要欄・タグ・視聴者コメントから」の抽象化**になります。
視聴者コメントは「どこが刺さったか」を本人たちが書いているので、
伸びた理由の材料としては字幕に劣らない面もあります。
字幕まで必要な場合は `collect.sh`（yt-dlp版）を YouTube に出られる環境で実行してください。

#### APIキーの取得手順
1. https://console.cloud.google.com/ でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」→ **YouTube Data API v3** を有効化
3. 「認証情報」→「認証情報を作成」→「APIキー」
4. 発行されたキーを `.env` に貼る

quota は1日10,000単位（無料）。本スクリプトは検索10クエリで約1,000単位、
残りは1単位/回の軽い呼び出しなので、1日に複数回実行できます。

### 解決の選択肢
1. **ローカル環境で `bash リサーチ/collect.sh` を実行する**（最短・推奨）。
   スクリプトは完成済みで、`data/videos.json`・`data/subs/*.txt`・`リサーチ/videos.md`
   を生成します。生成後にこのリポジトリへコミットいただければ、第1〜4章を作成します。
2. この環境のネットワークポリシーで `youtube.com` を許可する。
3. **`.env` にAPIキーを入れて `collect_api.sh` を実行する**（この環境のまま進められる）。
   字幕の代わりに概要欄・タグ・上位コメントで第1〜4章を作成します。

## 参考：スクリプトの使い方

```bash
# デフォルト（10本）
bash リサーチ/collect.sh

# 本数・検索幅・閾値を変えたいとき
WANT=15 PER_QUERY=80 MONTHS=6 MIN_VIEWS=10000 MAX_SUBS=10000 bash リサーチ/collect.sh
```

出力:
- `data/videos.json` — 採用動画のメタデータ（登録者数・再生数・登録者比など）
- `data/subs/<id>.vtt` / `data/subs/<id>.txt` — 字幕の原本とプレーンテキスト
- `リサーチ/videos.md` — 一覧表（本ファイル第1章にそのまま使える形式）
