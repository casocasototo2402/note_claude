# サンプルデータ（実データではありません）

パイプラインと `リサーチ/リサーチ.md` の出力フォーマットを、実データ取得前に
確認するための**架空のデータ**です。

- `videos.json` — 10本分のメタデータ（架空）
- `subs/SAMPLE*.txt` — 各動画の字幕（架空）

## 実データと区別できるようにしてあること

| 項目 | サンプル | 実データ |
|---|---|---|
| 動画ID | `SAMPLE00001` 形式 | YouTubeの11桁ID（例 `dQw4w9WgXcQ`） |
| チャンネル名 | `サンプルチャンネルA`〜`J` | 実名 |
| タイトル | 先頭に `【サンプル】` | なし |
| URL | `example.invalid`（到達しないドメイン） | `youtube.com` |
| JSONフィールド | `_sample: true` を持つ | 持たない |
| 字幕1行目 | 「サンプル字幕です」と明記 | なし |

**このデータを分析結果として使ってはいけません。**
実在の動画・チャンネル・再生数を一切含みません。

## 置き場所

実データは `data/videos.json` と `data/subs/` に入ります（このフォルダの外）。
混ざらないよう分離してあります。
